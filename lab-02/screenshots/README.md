# Screenshots Directory

Save your Postman test screenshots in this folder with the following filenames:

1. `01_get_all_books.png`: Postman GET request to `http://localhost:3000/books/` showing status 200 OK and JSON array.
2. `02_get_book_by_id.png`: Postman GET request to `http://localhost:3000/books/1/` showing single book details.
3. `03_post_new_book.png`: Postman POST request to `http://localhost:3000/books/` with JSON body and 201 Created.
4. `04_put_update_book.png`: Postman PUT request to `http://localhost:3000/books/:bookId/` with updated values and 200 OK.
5. `05_delete_book.png`: Postman DELETE request to `http://localhost:3000/books/:bookId/` showing 200 OK.
6. `06_sqlite_cli_view.png` or `06_database_verification.png`: Terminal output or DB Browser showing records in `books.db`.
